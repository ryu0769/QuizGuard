# 刷吧!少年 / shuaba.app — 儿童手机时长管控 App

> **题库来源与版权说明**：本仓库公开分发的唯一题库为 `app/src/main/assets/banks/primary/grade2/shang/math.json`（10586 题）。其中 10506 题为按 100 以内加减法、表内乘法等运算规则穷举得到的算式组合，属通用数表 / 公式级事实数据，**不含任何教材或教辅中的原题、题干文字、插图或章节编排**。章节名与「年级 / 册别 / 教材版本」等字段仅用作知识点索引与难度分级，不表示与任何出版社教材存在关联或配套关系；本项目非官方产品，未获任何出版社授权或背书。语文 / 英语 / 初中等外部题库均按 `.gitignore` 排除，未随源码分发。详见 [题库目录说明](app/src/main/assets/banks/README.md)。

> 中文名：**刷吧!少年** · 英文名 / 品牌：**shuaba.app** · 工程代号：`QuizGuard`（目录与包名保持不变）

开启守护后，孩子可**正常使用手机、自由切换后台**；倒计时归零时**自动弹出全屏答题界面**并强制钉屏，从**家长选定的出题范围**随机抽题，**全部答对才能继续玩**。**点选项即作答：答对自动进入下一题；答错会停在解析页展示正确答案与解题思路，孩子看懂后手动点「下一题」才继续**，做错的题稍后还要重做，直到全部答对。另有**错题本**：所有错题按**艾宾浩斯遗忘曲线**排期，到期后优先混入后续每一轮答题，反复刷到「已掌握」为止。

家长控制台可自定义：**每轮间隔（5~30 分钟）· 出题范围（学段 → 年级（含「综合（跨年级）」） → 上册/下册/全部 → 语数英/其它学科/全部）· 每次做题数量（1~5 道）· 答错处理（错题重做 / 整组重来）· 错题本复习（每轮 0~3 道 / 额外加练）**。科目选「全部」即多科随机混合出题；年级选「综合（跨年级）」即**该学段全部年级混合出题，数学、语文、英语都能跨年级**（1.0.12 起）。题目数据内置本地存储（`assets/banks/`），可离线使用、可自行增删改。**内置题库**：对应教材版本（一年级起点）**英语** 1132 题（v1.0.11 替换为校订版）、对应教材版本（统编/部编版）**语文** 3074 题、小学**数学**一至六年级上册（二年级 10586 题 + 其余 5 册 6234 题）、**初中七年级上册 7 科** 170 题。二年级上册科目切「全部」即**语文 + 数学 + 英语三科混合出题**；学段切到「初中」可选语文 / 数学 / 英语 / 道德与法治 / 历史 / 地理 / 生物。

## 一、先说清楚：哪些能做到，哪些做不到（很重要）

本工程默认提供 **「可切后台 + 到点自动弹出」** 模式：开启守护后孩子能**正常使用手机、自由切换 App**；每 10 分钟倒计时归零，App 会**自动把全屏答题界面拉到最前面**强制答题，答完才放行。守护由**前台服务**保活，切后台、锁屏也不中断计时。

需要诚实说明安卓系统的限制：
- **Home 键无法靠 App 禁用**（系统级，事件不发给应用）。本方案的处理是：**非答题阶段允许自由使用**；一旦到点答题，立刻用系统「屏幕固定（Lock Task）」把答题界面钉死，此时系统**自动禁用 Home/Recent**，孩子无法中途退出，必须答完。
- 所以"强制力"集中在**答题那几分钟**；其余时间孩子是自由使用的——这正是需求里"开启后可以切换后台"想要的效果。
- 若需要"从开启到结束全程钉死、任何时刻都不能切走"，请走文末「模式 B：设备所有者 kiosk」。
- **国产 ROM（小米 MIUI / 红米等）** 默认禁止"后台弹出界面"，可能导致到点弹不出答题框；需到设置里授权（详见「二、运行模式」模式 C 的提示）。本版已从「仅后台 startActivity」升级为**全屏 Intent 通知（闹钟式 heads-up）**兜底，到点会以最高优先级把答题界面顶到最前，大幅降低弹不出的概率；仍建议按模式 C 提示给"刷吧!少年"开「后台弹出界面 / 自启动」权限作为双保险。

| 需求 | 本工程实现方式 | 说明 |
|------|----------------|------|
| 每 10 分钟自动弹出 | `GuardState` 单例倒计时（前台服务保活）+ 到点**全屏 Intent 通知**拉起答题界面（head-up，MIUI/锁屏也能弹） + 兜底 `startActivity` | 守护在前台服务里，子机可后台、可切 App |
| 开启后可自由切换后台 | 非答题阶段不钉屏，仅计时保活 | **默认新行为**：孩子能正常用手机，到点才被叫回来答题 |

## 二、运行模式（默认即可用，强制度可升级）

### 模式 C（默认）：可切后台 + 到点自动弹出（无需任何电脑设置）
1. 安装并打开「刷吧!少年」→ 点「开启守护」。
2. 此时 App 退到后台、常驻通知栏，孩子可**正常使用手机、切换任意 App**。
3. 每 10 分钟倒计时归零 → **自动弹出全屏答题界面并钉屏**，连做 3 题全对才放行（点选项即判定：答对自动跳下一题，答错看完解析再手动继续），回到刚才的 App 继续玩 10 分钟，循环往复。
4. 守护中随时可在 App 内「停止守护」，或右下角「家长」按钮进入控制台接管。

> **国产 ROM（小米 MIUI / 红米等）重要提示**：MIUI 默认禁止"后台弹出界面"，可能导致到点弹不出答题框。请到
> 「设置 → 应用设置 → 授权管理 → 自启动 / 后台弹出界面 / 悬浮窗」中，给「刷吧!少年」全部设为允许；
> 并在「电池与性能 → 应用配置」把刷吧!少年设为"无限制"（关闭省电限制）。
> 即使被系统拦截，到点时也会推送一条"该答题啦"通知，点击同样能进入答题。

### 模式 A：普通钉屏（答题阶段更强锁，无需电脑）
若担心孩子趁答题间隙退出，可额外在系统开启屏幕固定，让答题界面锁得更死：
1. 手机「设置 → 安全 → 屏幕固定（Screen Pinning）」开启，并打开"固定时锁定设备"（如有）。
2. 打开「刷吧!少年」并开启守护；答题阶段 App 会自动尝试 `startLockTask()` 钉屏。
3. 此后**答题期间**屏幕被钉住，Home/Recent 被禁用；非答题时段仍可按 Home 自由切换。
4. **退出钉屏**：同时按住「返回 + 最近任务」键（部分机型为长按多任务），输入锁屏密码即可退出。
   - 这是系统留的"家长出口"，无法被 App 消除。

### 模式 B：设备所有者 kiosk（全程锁死，需一次电脑 adb）
适合长期托管、绝不让孩子退出（从开启到结束全程不可切走）：
```bash
# 手机开启 USB 调试，连电脑后执行（仅需一次）
adb shell dpm set-device-owner com.quizguard.app/.AdminReceiver
```
之后打开 App 即进入不可退出的锁定态（代码内 `dpm.setLockTaskPackages` 已白名单本应用）。
**解除锁定**：`adb shell dpm remove-active-admin com.quizguard.app/.AdminReceiver`，或在设置里停用设备管理员。

> 模式 B 下若要彻底卸载，需先 `remove-active-admin` 再卸载。

## 二之一、家长解锁密码（家长接管孩子手机用）

为防止孩子自己退出管控或误触，刷吧!少年内置**家长解锁密码**：

- **默认密码 `1234`**，首次启动自动写入（仅存 SHA-256 哈希，不存明文）。
- 守护页右下角有低调的「家长」按钮 → 输入密码 → 进入**家长控制台**：
  - **继续守护（10 分钟）**：关闭控制台，重新计时 10 分钟；
  - **修改密码**：校验旧密码后设置新密码（≥4 位，仅数字）；
  - **退出管控**：解除钉屏并返回桌面（详见下方"退出"说明）。
- **防暴力试密**：连续输错 5 次锁定 60 秒，期间无法再试。
- 密码校验、修改、锁定逻辑全部在 `core/ParentPrefs.kt`，无网络、不上传。

> 建议：第一次使用时进入家长控制台把默认密码 `1234` 改成你专属的密码。

**退出管控说明**：
- 普通钉屏模式（模式 A）：点「退出管控」即解除钉屏、返回桌面；
- 设备所有者 kiosk 模式（模式 B）：系统会强制拉回本应用（防儿童退出），**彻底解除**需电脑执行
  `adb shell dpm remove-active-admin com.quizguard.app/.AdminReceiver`。

## 五、题库怎么改（四级 Catalog，v1.0.4 起）

> 📖 **完整字段表、JSON 示例、初高中多学科接入步骤、校验脚本、版权提醒见 [QUESTION_BANK_FORMAT.md](QUESTION_BANK_FORMAT.md)**

题库按 **学段 → 年级 → 册别 → 科目** 四级组织，App 递归扫描 `assets/banks/` 下所有 `.json`，
读每个文件头部 4KB 的 `meta` 建索引；**丢文件即自动出现在家长台，零改代码**。

```
app/src/main/assets/banks/
├── primary/                              # 学段：primary 小学 / junior 初中 / senior 高中
│   ├── grade1~grade6/{shang,xia}/
│   │   ├── chinese.json                  # 语文 12 册（统编版，3023 题）
│   │   ├── english.json                  # 英语 12 册（一年级起点体系，1092 题；未随源码公开）
│   │   └── math.json                     # 数学上册：一 / 三 / 四 / 五 / 六年级（6234 题）
│   ├── grade2/shang/math.json            # 二年级上册数学（原有 10586 题）
│   ├── shared/all/
│   │   ├── chinese.json                  # 语文综合专项（51 题）
│   │   └── english.json                  # 英语综合·词汇分类（40 题）
│   │                                    # ↑ grade_id=shared；1.0.12 起并入「综合（跨年级）」聚合池
├── junior/                               # ✅ 初中已接入（v1.0.11）
│   └── grade7/shang/
│       ├── chinese.json / math.json / english.json
│       └── politics.json / history.json / geography.json / biology.json
└── senior/                               # ← 高中接入位（高一~高三）
```

- **归类规则：meta 优先，目录兜底。** `meta` 写 `stage / grade_id / grade_label / term / subject / subject_label / edition`；
  缺省时按目录层级与文件名推断，因此 v1.0.3 的 `banks/<年级>/<科目>.json` 旧布局仍可用（册别按 `meta.grade` 文本推断，无册别信息则归「全册」）。
- **册别目录**：`shang` 上册 / `xia` 下册 / `all` 全册。选「上册」会连 `all/` 通用题一起并入；选「全部」= 三册合并。
- **科目文件名**：`math / chinese / english / physics / chemistry / biology / history / geography / politics / science / it`；
  未知科目写 `meta.subject_label` 即可自定义（如「通用技术」）。
- 顶层 JSON 支持 `{"meta":{...},"questions":[...]}` 和纯数组 `[...]`；只加载选择题（`options ≥ 2`、`answerIndex` 合法、`text` 非空）。
- 全范围无合法题时回退内置 24 题兜底；大题库按范围**后台按需解析 + 按文件路径缓存**，不卡启动。

**家长控制台 —— 出题范围四级联动**

| 层级 | 默认值 | 可选项 | 说明 |
|------|--------|--------|------|
| 学段 | 小学 | 小学 / 初中 / 高中 | 小学与初中已有题库（七年级上册 7 科），仅高中仍置灰 |
| 年级 | 二年级 | 小学：一年级 ~ 六年级 / **综合（跨年级）**；初中：七年级 | 自动列出该学段所有年级；选「综合（跨年级）」= 该学段**全部年级题库合并**（至少 2 个真实年级时才出现），数学 / 语文 / 英语都能跨年级混合 |
| 册别 | 上册 | 上册 / 下册 / 全部 | 三项固定显示；无题库的置灰（语文、英语各 12 册齐全） |
| 科目 | 数学 | 全部 / 语文 / 数学 / 英语 + 实际存在的其它学科 | **选「全部」= 多科随机混合出题**；二年级上册 = 语文 + 数学 + 英语；七年级上册另有道法 / 历史 / 地理 / 生物 |
| 每轮答题间隔 | 10 分钟 | 5 / 10 / 15 / 20 / 30 分钟 | 立即重启本轮计时 |
| 每次做题数量 | 3 道 | 1 / 2 / 3 / 4 / 5 道 | 下一轮答题生效，不打断当前组 |
| 答错处理 | 错题重做 | 错题重做 / 整组重来 | 下一轮答题生效；两种策略答错都会停在解析页等待手动继续 |
| 每轮错题复习（v1.0.6） | 2 道 | 关闭 / 1 / 2 / 3 道 | 占用本轮题数；设为「关闭」时错题仍继续收集，只是不插入答题 |
| 额外加练（v1.0.6） | 关 | 开 / 关 | 开启后错题**不占**本轮题数，本轮题数 = 新题数 + 到期错题数 |

切换上级时下级会自动回落到有效组合（`QuestionBank.normalize`），不会出现「选中却无题」。
跨年级且选了「数学 + 下册」这类「该科目在此册别无题」的组合时，会**优先把册别放宽到「全部」以保留科目**，不会把科目悄悄踢回「全部」。

**「综合（跨年级）」怎么工作（v1.0.12）**：App 把 `grade_id = shared` 定义为**全学段聚合年级**，
`grades()` 在学段有 ≥2 个真实年级时自动追加（初中目前只有七年级，故不显示）。选中后 `resolve()`
跳过年级过滤，把该学段所有年级的题库 + `shared/all/` 的综合专项文件合成一个池：小学册别选「全部」时
≈ 数学 16798 题 + 语文 3074 题 + 英语 1132 题；科目选「数学」就是一~六年级题目真正混出。
**它不需要 `shared/all/math.json`**——想让新科目支持跨年级，照常把文件放进对应年级目录即可，零改代码。
（v1.0.11 及以前，`shared` 只是「只有语文 / 英语两个综合专项文件的普通年级」，所以数学在那里被置灰。）

**组卷规则**：科目选「全部」时，从该范围**每个有题的科目各先抽 1 道**（科目顺序打乱），不足题数再从合并池去重补足；
选具体一科则只从该科抽题。答错任意一题 → 先停在解析页；手动继续后，按家长设置的「错题重做」（只重做做错的题，默认）或「整组重来」（重新抽一整组）处理，直到全部答对。

> **当前内置数据**：
> - `primary/grade2/shang/math.json`：**二年级上册数学（通用课标知识点·穷举算式）**（10586 题，选择题 10564 可用）。

## 七、已知限制（务必知道）

1. **默认模式（模式 C）下，非答题时段孩子可自由切换后台**——这正是需求要的"开启后可以切换后台"。强制管控集中在**答题那几分钟**（到点自动拉起并钉屏）。
2. **Home 键无法靠 App 禁用**，答题阶段的钉屏由系统提供；国产 ROM（MIUI 等）可能拦截"后台弹出界面"，需在系统设置授权（见模式 C 提示），否则到点用"该答题啦"通知兜底进入。
3. **电源键无法禁用**，孩子可长按电源锁屏；但钉屏/答题状态下解锁后会直接回到答题界面。
4. 若需"全程不可退出"的强管控，请走模式 B（设备所有者 kiosk），用 `adb` 一次性授权。
5. 题库现为**多学段目录架构**（小学数学 6 册 16798 题 + 小学一至六年级英语 1132 题 + 小学语文 3074 题 + 初中七上 7 科 170 题，共 39 个 JSON）；新增年级/科目只需放 JSON 文件，格式见 `QUESTION_BANK_FORMAT.md`。英语「词义填空」、语文「拼音 / 字词 / 诗句填空」与初中「blank」均为转换成的选择题，干扰项按题型分层取自同类答案，个别题可能偏易。**初中标准化试卷里的多选 / 简答 / 作文 / 识图 / 计算 / 证明题共 48 道未接入**（App 只支持 4 选 1），原始文件保留在 `sources/`。**开源发布前请先确认各批题库数据与头像素材的版权/授权**。
6. **v1.0.16 起每一轮答题都会重新申请系统「屏幕固定」**：v1.0.3~v1.0.15 为了让系统确认框别反复弹，用了「每进程只申请一次」的闸门；但每轮答完都会 `stopLockTask()`，于是**第 2 轮起系统钉屏从未真正生效**，只剩 0.35 秒的防逃逸回拉——手快的孩子正好在这个窗口里切走并清进程。现在改为按 `quizSerial` 每轮申请一次：家长在系统里开启屏幕固定并关掉「固定前询问」后，每轮都是静默锁死；系统仍询问时，同一轮内也只弹一次，不会连环弹。若要求绝对无弹窗、孩子无法取消固定，请走模式 B（Device Owner）。
7. **最近任务键（多任务）无法被普通 App 禁用**：`KEYCODE_APP_SWITCH` 在多数 ROM 由 SystemUI 直接处理、根本不派发给应用（代码里自 v1.0.2 起就在 `dispatchKeyEvent` 尝试拦截，实际挡不住）。v1.0.16 的对策分三层：**系统屏幕固定每轮生效**（真正隐藏 Home / 最近任务）→ 答题期 120ms 轮询 / 0.35 秒拉回 → 进程被「最近任务 → 清除」时 `onTaskRemoved` 秒恢复、真被回收则 8 秒看门狗复活并重新出题。但 **MIUI 等 ROM 未授予「自启动 / 电池无限制」时静态广播可能收不到**，复活会延迟甚至失效；系统设置里的「强制停止」会 forceStop 本应用——取消所有闹钟、静态广播不再派发，此时任何代码都失效，只能由家长重新打开（这是 Android 平台硬边界）。

## 十、本次修复（2026-11-05 第三轮，响应实测反馈）

1. **自定义时间「选不了」**：`GuardState.cycleMs` 原为普通 `var`，改值后 Compose 不重组，导致选项高亮与「当前 X 分钟」文字不刷新，外观像选不中。现改为 `mutableStateOf` 暴露，切换选项即时高亮生效。
2. **家长面板内「立即弹出测试题」无效**：`GuardScreen` 的 `when` 判定中 `parentMode` 优先级高于 `phase==QUIZ`，在面板内点出题会进入答题阶段却仍被面板盖住、永远出不来。现 `testFire()` 先退出家长模式再触发；同时 `MainActivity` 增加 `LaunchedEffect(phase, parentMode)` 在状态切换（哪怕不触发生命周期）时自动重同步锁屏，保证立即出题会真正弹出并锁屏。
3. **面板内改时长不再「暗中计时」**：仅记录新时长，等待家长退出面板（`exitParentMode`）时才按新时长重启倒计时；避免面板里计时还在走、到点把答题界面藏到面板后的混乱。
4. **答题后通知还原**：3 题全对解除锁屏后，通知从「该答题啦」还原回「守护中」，避免答题后长期停在提醒通知。

## 十一、做题时还能切换到其它程序？（v1.0.2 专题）

### 为什么会发生

`startLockTask()`（屏幕固定）在**普通安装**下并不是 App 单方面能开启的：必须先在
`系统设置 → 安全 → 屏幕固定` 里打开该功能并确认授权，否则调用会抛异常（旧版被 `catch`
静默吞掉），结果就是**钉屏根本没生效** → 答题时按 Home / 多任务键可以切走。
此外 Android 系统不允许第三方 App 拦截 Home 键事件，**唯一能 100% 禁用 Home/Recent 的
方式是「设备所有者（Device Owner）」或系统屏幕固定**。

### v1.0.2 做了三层处理

| 层 | 机制 | 是否需要额外授权 |
|----|------|------------------|
| 1. 防逃逸守护（默认生效） | **三层兜底**：① `GuardService.onTaskRemoved`——孩子上滑清掉 App 主任务时（前台服务进程未死）立即把答题界面顶回前台，秒恢复；② `GuardState` 每 120ms 检查前台标志，离开后 350ms 节流拉回；③ `GuardWatchdog` 8 秒闹钟——进程被系统真正回收后自动复活守护并重新出题 | **不需要**，纯 App 逻辑，靠前台服务保活 |
| 2. 真实状态检测（新增） | `ActivityManager.getLockTaskModeState()` 判定钉屏是否真生效，不再「以为锁住了」；答题页与家长台如实显示「🔒 已锁定」/「⚠️ 未生效」 | 不需要 |
| 3. 家长开启入口（新增） | 家长控制台提供「去开启系统『屏幕固定』」跳转按钮 + `adb shell dpm set-device-owner` 命令提示 | 需家长在系统设置开启，或电脑执行一次 adb |

另外修正：答题阶段 `onPause` 不再无条件 `releaseLock()`（旧逻辑等于「一按 Home 就自动解锁」）。

### 想彻底切不走，二选一

- **方式 A（推荐，无需电脑）**：手机 `设置 → 安全 → 屏幕固定` 开启并勾选「固定时要求解锁」；
  之后答题时 Home / 最近任务键被系统禁用。注意系统仍保留「同时长按返回 + 最近任务」的
  家长退出组合键，这是 Android 设计，无法消除。
- **方式 B（最彻底，一次 adb）**：电脑连手机执行
  `adb shell dpm set-device-owner com.quizguard.app/.AdminReceiver`
  之后 `startLockTask()` 无条件生效且**无法用组合键退出**，答题期间真正切不走。
  解除：`adb shell dpm remove-active-admin com.quizguard.app/.AdminReceiver`。

> 说明：即使不做 A/B，v1.0.2 的防逃逸守护也会让孩子「切走立刻被拉回」，实际用不了其它
> App；但 MIUI 若严格拦截「后台弹出界面」，请按「二、运行模式 → 模式 C」给刷吧!少年放开
> 自启动 / 后台弹出界面 / 悬浮窗权限，以确保拉回通知能顶起界面。

## 十四、v1.0.5 本轮改动（2026-11-05 第六轮：点选项即作答 + 错题讲解停留）

### 1. 交互改动

| 场景 | 之前（v1.0.4） | 现在（v1.0.5） |
|------|----------------|----------------|
| 作答 | 先点选项，再点「提交答案」 | **点一下选项立即判定**，取消提交按钮 |
| 答对 | 650ms 后自动进入下一题 | 600ms 绿色反馈后**自动跳过**到下一题；最后一道直接放行 |
| 答错 | 850ms 后自动重抽整组，解析一闪而过 | **停在原题不跳转**，展示正确答案 + 解题思路，必须手动点「看懂了，下一题」 |
| 解析展示 | 一行小字，容易被下一屏冲掉 | 独立解析卡片（可滚动），正确选项标绿为「✓ 正确答案」，无解析时给出兜底提示 |
| 底部 | 「提交答案」按钮 | 未作答提示 / 答对进度提示 / 答错时的手动继续按钮，三者随状态切换 |

设计目的：正确题不打断节奏，错误题留足时间理解解题思路。内置 10586 道数学题**全部带 `explanation`**，正好用于这一步。

### 2. 答错处理策略（家长台可选，持久化）

- **错题重做（默认）**：答错的题排进 `wrongQueue`，本组其余题照常做完，队尾再进入「错题重做轮」；把错题全部答对才放行。已答对的题不用重来，挫败感更低。
- **整组重来**：沿用 v1.0.4 行为，答错一道就 `randomN()` 重抽一整组，从第 1 题重做。
- 策略在每轮出题时取**快照 `roundPolicy`**，家长中途改设置只影响下一轮，不会打乱正在进行的一组题。
- 两种策略都遵循「**全部答对才解除钉屏**」；错题重做轮在答题页顶部有「🔁 错题重做」提示条。

### 3. 布局与健壮性

- 题目、选项、解析放进 `Modifier.weight(1f).verticalScroll()` 内容区，底部按钮固定在屏幕下方：解析再长也不会把按钮挤出屏幕。

- 保留 `select()` / `submit()` 兼容入口，`submit()` 等价于对当前选中项执行一次 `answer()`。
- 顺手修掉 v1.0.4 遗留：「全部答对，可以继续玩 N 分钟」的提示原先会被 `startCycle()` 里的 `notice = null` 立刻清掉，现已移到重新计时之后；「整组重来」的提示改由答题页顶部的轮次提示条显示。

## 十五、v1.0.6 本轮改动（2026-11-05 第七轮：错题本 + 艾宾浩斯遗忘曲线）

### 1. 错题本数据

- 新文件 `core/WrongBook.kt`，独立 SharedPreferences `quizguard_wrongbook` 存一份 JSON（上限 500 条，超出优先淘汰已掌握的旧题）。不引入 Room / Gson，用 Android 内置 `org.json`。
- 每条记录 `WrongEntry`：`key`（科目 + 题干 + 选项的 SHA-256 前 20 位）、题目完整快照、累计答错次数、复习答对次数、当前档位 `stage`、下次复习时间 `dueAt`、最近结算时间、是否已掌握。
- 存**题目快照**而非题目 id：家长切换年级 / 科目、甚至替换题库文件后，旧错题依然能被复习到；指纹保证同一道题不会重复入本。
- `WrongBook.version` 用 `mutableStateOf` 暴露，家长台统计在错题变化后即时刷新。

### 2. 艾宾浩斯复习排期（核心）

| 档位 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|------|---|---|---|---|---|---|---|---|---|
| 间隔 | 5 分钟 | 30 分钟 | 12 小时 | 1 天 | 2 天 | 4 天 | 7 天 | 15 天 | 30 天 |

- **入本**：答错一道新题 → 立刻记为第 1 档，5 分钟后到期（通常正好是下一轮答题）。
- **到期取题**：每轮出题时 `WrongBook.due(limit)` 取 `dueAt <= now` 的题，**越早到期越优先；同时间错得越多的越优先**，最多取家长设的道数（默认 2）。
- **组卷**：到期错题 + 新题打乱组成本轮题目。默认错题**占用**本轮题数（总题数不变）；打开「额外加练」则叠加，本轮题数 = 新题数 + 错题数。新题会过滤掉与复习题指纹相同的题，避免同一轮重复出同一道。
- **复习答对**：`stage + 1`，下次复习 = 现在 + 下一档间隔；连续 9 档全对 → `mastered = true`，不再出现（家长台显示 🎉 已掌握）。
- **复习答错**：`stage = 0`、错误次数 +1、5 分钟后重新刷 → **错得越多刷得越勤**。
- 同一道题**每轮只结算一次**（`recordedThisRound`），本轮内的「错题重做」不会把复习曲线反复推进 / 回退。
- 答题页对复习题显示「📕 复习 N」chip，判定后显示「下次复习：约 X 后（第 N/9 档）」。

### 3. 家长台

- 新增「📕 错题本」卡片：总题数 / 待复习 / 已掌握、完整复习节点、最近一次复习倒计时、「查看 / 管理错题」入口。
- 错题列表弹窗：题干、科目、错误次数、复习答对次数、当前档位、下次复习时间；可**移除单题**或**清空整本**（二次确认，不可恢复，列表最多显示前 50 条）。
- 新增设置「每轮错题复习（关闭 / 1 / 2 / 3 道）」与「额外加练」开关，均持久化。
- 「关闭」只是暂停把错题插入答题，**答错仍会继续入本**，随时可再打开。
- 守护中倒计时页另有「📕 我的错题本」入口，孩子**无需密码即可只读查看**自己的错题与复习进度（不能移除 / 清空，也不显示答案）。

### 4. 与 v1.0.5「本轮错题重做」的区别

| | 本轮错题重做（v1.0.5） | 错题本复习（v1.0.6） |
|---|---|---|
| 时间尺度 | 同一轮答题内，答完立刻重做 | 跨轮、跨天、重启后仍保留 |
| 触发 | 本组出现答错 | 艾宾浩斯节点到期 |
| 结束条件 | 本组全部答对 | 连续 9 档复习全对 → 已掌握 |
| 目的 | 当场订正 | 抗遗忘、长期巩固 |

两者叠加不冲突：当场订正解决「看懂解析」，隔期复习解决「过几天又忘」。

### 5. 验证路径

1. 家长台把「每轮错题复习」设为 2、「答错处理」保持「错题重做」，点「立即弹出测试题」；

3. 把间隔调到 5 分钟（或等 5 分钟后再点「立即弹出测试题」），新一轮应出现带「📕 复习 1」标记的同一道题；

原库有 `choice` 1599 题 + `fill` 1475 题，App 只加载选择题。语文填空的答案类型很杂：
拼音音节（`ping`）、带声调拼音（`cháng`）、汉字词语（`奇观`）、诗句（`二月春风似剪刀`）、
数字（笔画数 / 声调序号）、单个字母（`H`）。若像英语那样只按「同册」取干扰项，
「看拼音写词语」题会出现 3 个拼音 + 1 个汉字词，孩子一眼看穿。因此导入时分层挑选：

- **同题型识别**：取题干中文冒号前的提示语并抹掉具体词例，例如
  `看拼音，写词语：qí guān →（ ）` 与 `看拼音，写词语：nóng lì →（ ）` 归为同一题型；
- **答案类型识别**：`digit` / `letter` / `hanzi` / `pinyin` 四类，干扰项只从同类型答案里取；
- **优先级**：同年级同册 + 同题型 → 同年级同册 + 同类型 → 全库同题型 → 全库同类型；
- 排除与正确答案相同 / 互相包含的字符串，选项随机打乱并重新定位 `answerIndex`；
- 凑不齐 3 个合法干扰项就跳过该题，**绝不生成有歧义的选项**（本库实际跳过 0 道）；
- 转换题带 `origin: "fill_to_choice"` 标记，原 `explanation` 完整保留，答错时照常展示解题思路。

导入后校验：**13 个文件 / 3074 题，4 个互异选项、`answerIndex` 合法、题干与解析非空、转换题选项类型一致，0 道非法题**。
源库自带的 10 道选择题存在「互相包含」的干扰项（如 `an` / `ang`、`画` / `画鸡`、`红旗` / `五星红旗`），
这是语文题刻意设计的辨析项，予以保留。

## 二十、v1.0.11 本轮改动（2026-11-06 第十二轮：任务栏防逃逸 + 题库大更新）

### 1. 第 1 问的结论：选「监测到就秒切回」，但必须再加一层进程复活

| 方案 | 普通侧载 App 能否做到 | 实际效果 |
|---|---|---|
| A. 不让切换任务栏（禁用最近任务键） | **做不到** | `KEYCODE_APP_SWITCH` 与 Home 键由 SystemUI 处理，多数 ROM（含 MIUI）根本不派发给应用。代码自 v1.0.2 就在 `dispatchKeyEvent` 里拦了，实际挡不住。只有**系统屏幕固定**（用户手动开）或 **Device Owner** 才真正隐藏它 |
| B. 检测到进入任务栏马上切回 | **能**，且是唯一现实路径 | 旧版 1200ms 轮询 + 2 秒启动宽限 + 3 秒拉回节流 = 最坏 **4~5 秒**才拉回，足够孩子上滑清进程。本版压到 250ms / 600ms / 700ms，最坏约 **1 秒** |

但只做 B 仍有个致命缺口：**一旦进程真的被清掉，前台服务、倒计时、防逃逸协程一起消失，App 无从自救**。所以本版做了三层：

1. **秒级回拉**（`GuardState`）：答题期每 250ms 检查前台标志，离开（含进入最近任务）后 700ms 节流拉回，最坏约 1 秒。全屏通知单独 5 秒节流，避免每 0.7 秒响一次。
2. **进程复活**（`GuardWatchdog`）：家长开启守护时持久化 `guardEnabled` 并挂 20 秒闹钟心跳；服务改 `START_STICKY`；进程被杀后由闹钟 / 开机广播唤醒，重启前台服务。Android 12+ 可能禁止「广播直接启动前台服务」，因此同时发一条全屏通知把 `MainActivity` 顶到前台，由它调用 `GuardControl.start()` 在前台重启服务。
3. **不白送时间**：`quizActive` 持久化答题阶段。若被杀时正在答题，复活后**立刻重新出题**；若只是守护中，则重新开始计时。家长点「停止守护 / 退出管控」会清掉 `guardEnabled` 并取消闹钟，**不会被复活成关不掉**。

> 想 100% 禁用最近任务键，仍只有一条路：`adb shell dpm set-device-owner com.quizguard.app/.AdminReceiver`（模式 B，系统不弹确认框且 Home / 多任务键由系统隐藏）。

## 二十一、v1.0.13 本轮改动（2026-11-06 第十三轮：切走关进程秒恢复）

### 1. 用户反馈与根因

反馈原文：**「还是能切换关闭进程，能不能再缩短检测时间，或者检测做題时被迫关闭进程会自动恢复」**。

排查后确认：v1.0.11/1.0.12 的防线里，**进程内的 250ms 防逃逸轮询只在进程活着时有效**；孩子从「最近任务」上滑清掉 App，进程被杀，前台服务、倒计时、防逃逸协程一起消失，只能等 **20 秒** 的 `GuardWatchdog` 闹钟把界面顶回来。这 20 秒空窗足够他切去别的 App 乱玩——这就是「还是能切走关进程」的真正原因。

### 2. 核心修复：`GuardService.onTaskRemoved` 秒恢复

前台服务（`startForeground`）有一个被忽视的关键事实：**孩子上滑清掉 App 主任务时，服务所在的进程并不会立刻死**（被前台服务保活），系统会先回调 `Service.onTaskRemoved()`。这正好是「切走秒恢复」的最佳时机：

- 回调内立刻把 `MainActivity` 用 `FLAG_ACTIVITY_NEW_TASK` 重新顶回前台；
- 重新挂一次常驻前台通知、续上心跳闹钟（防进程随后真被回收）；
- 因为 `GuardState` 单例还在，若被杀前正处于答题阶段（`phase=QUIZ`），`MainActivity.onResume` 会自动重新进入锁屏并续上原题，题目与进度**完全不丢**；
- 带入 `EXTRA_FROM_KILL` 标记，让 `MainActivity` 恢复瞬间立即重进锁屏，不留可操作空窗。

> 个别 ROM（如 MIUI 强杀）若在 `onTaskRemoved` 之后真的回收了进程，则退化为 8 秒看门狗兜底；两条路径合起来覆盖「切走」与「进程被杀」两种逃逸。

### 3. 收紧检测时间

| 参数 | v1.0.11/1.0.12 | v1.0.13 |
|---|---|---|
| 防逃逸轮询间隔 | 250ms | **120ms** |
| 启动宽限 | 600ms | **300ms** |
| 拉回节流 | 700ms | **350ms** |
| 全屏通知节流 | 5s | **3s** |
| 看门狗闹钟 | 20s | **8s**（进程真被杀后的兜底） |
| 上滑清任务恢复 | 等 20s 闹钟 | **onTaskRemoved 秒恢复** |

### 4. 验证路径

1. 覆盖安装 v1.0.13（保留密码与错题本）→ 家长台（1234）→ 立即弹出测试题；
2. 答题中按最近任务键 / 上滑进多任务界面 → 应约 **0.5 秒**内被拉回；
3. 在任务栏里**上滑清除进程** → 应**几乎立即**自动弹回答题界面（不再等 20 秒）；若 ROM 强杀导致进程真死，则约 **8 秒**内由看门狗复活并重新出题；
4. 家长台点「停止守护」→ 等 15 秒确认**不再**自动复活（防止关不掉）；
5. `aapt dump badging` 确认 `versionCode=14`、`versionName=1.0.13`、桌面名「刷吧!少年 / shuaba.app」。

## 二十二、v1.0.14 本轮改动（2026-11-06 第十四轮：多机型适配层）

## 二十四、v1.0.16：为什么「手速快还是能杀掉进程」，以及怎么修

### 1. 真正的根因（不是速度问题）

用户反馈「手速快的时候还是能切换后台马上关掉进程」。排查后发现两层原因，第一层是代码 bug，第二层是平台边界：

| # | 原因 | 说明 |
|---|---|---|
| **① 代码 bug（已修）** | **第 2 轮起系统钉屏根本没生效** | v1.0.3 为了不让系统确认框反复弹，用 `ProcessOnce` 做了「每进程只申请一次 `startLockTask()`」的闸门。但每轮答完都会 `stopLockTask()`，而第 2 轮再进答题时 `ProcessOnce` 已返回 false → **不再调用 `startLockTask`**。于是整场只有第一轮真正锁死，之后全靠 0.35 秒的防逃逸回拉——手快的人正好在这个窗口里完成「切最近任务 → 上滑」 |
| **② 平台边界（不可修）** | 桌面 / 安全中心的「一键清理」 | 走系统 `forceStop`：不回调 `onTaskRemoved`、取消所有 AlarmManager 闹钟、**静态广播从此不再派发给本应用**。看门狗、`START_STICKY`、开机广播全部失效，只能家长手动重开 App。这是 Android 的安全设计，第三方应用无法对抗 |

### 2. 修复内容

**每轮重新申请锁定（核心）**

- `GuardState` 新增 `quizSerial`，每次 `fireQuiz()` 递增；
- `MainActivity.enterLockTask()` 改为按 `quizSerial` 判断「本轮是否已申请」，**每轮答题都重新 `startLockTask()`**；
- 同一轮内只申请一次（`onStart/onResume/onNewIntent/LaunchedEffect` 多次触发也不会连环弹框）；
- Activity 不在前台时**不计入**申请名额（后台调用 `startLockTask` 必然失败，等 `onResume` 再来，避免把机会浪费在后台）；
- Device Owner 模式每轮先 `setLockTaskPackages`，锁定无弹窗且孩子无法取消。

**新增「🔒 锁死向导」**（家长台，锁定状态卡片下方）

| 检查项 | 数据来源 | 含义 |
|---|---|---|
| ① 系统「屏幕固定」 | `Settings.Secure["lock_to_app_enabled"]` | 关闭时孩子能进最近任务，是一切的根源 |
| ② 取消固定需要解锁 | `Settings.Secure["lock_to_app_exit_locked"]` | 不开的话孩子自己就能取消固定 |
| ③ 设备所有者 | `DevicePolicyManager.isDeviceOwnerApp()` | 最彻底：无弹窗、不可取消 |

三项均给 ✓ / ✗ / ○（读不到该键的 ROM 显示 ○ 请确认），并显示「本次状态：已锁定 / 未锁定」，1.5 秒轮询刷新，从系统设置返回无需手动重进。分品牌给出路径提示（小米/黑鲨、OPPO、vivo、华为、努比亚、三星各不相同）。

**兜底再加一层**：`onTaskRemoved` 里 `startActivity` 失败时立即补发全屏通知，不再干等 8 秒看门狗。

### 3. 正确设置一次，效果差别

| 设置状态 | 孩子切后台 | 孩子上滑清任务 | 孩子「一键清理」 |
|---|---|---|---|
| 屏幕固定未开（默认） | 0.35 秒内被拉回 | 通常秒恢复 | **失效**（forceStop） |
| 屏幕固定开启 + 取消需解锁 | **进不去最近任务** | 无从下手 | 仍可能 forceStop，但孩子在锁定的答题界面里点不到桌面清理入口 |
| 设备所有者 | 完全锁死 | 完全锁死 | 系统不允许 forceStop 本应用 |

> 结论：**开启屏幕固定是普通安装下唯一能根治「手速快杀进程」的手段**，而 v1.0.16 修好了「只有第一轮生效」的 bug。要连「一键清理」也堵死，只能走 Device Owner。

### 4. 验证路径

1. 覆盖安装 → 家长台（1234）→「🔒 锁死向导」应显示 ①②③ 三项状态；
2. 按提示开启屏幕固定、打开「取消固定需要解锁」，返回后 1.5 秒内 ①② 变 ✓；
3. 点「立即弹出测试题」→ 答题界面出现时按 Home / 最近任务：**应完全无反应**（不是被拉回，而是根本进不去）；
4. 连答两轮，第 2 轮重复上一步，确认**第 2 轮同样锁死**（这是本版修的核心）；
5. 若系统仍弹「固定屏幕？」确认框：说明没关「固定前询问」，关掉后即静默；
6. `aapt dump badging` 确认 `versionCode=17`、`versionName=1.0.16`。
